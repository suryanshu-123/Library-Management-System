 📚 Library Management System (Full Stack)

A full-stack web application to manage books using Node.js, Express, and MongoDB.

## 🚀 Features
- Add Books
- Delete Books
- View Books
- REST API Integration

## 🛠️ Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Database: MongoDB

## ▶️ How to Run

1. Install dependencies
npm install

2. Start server
npm start

3. Open frontend
Open client/index.html
